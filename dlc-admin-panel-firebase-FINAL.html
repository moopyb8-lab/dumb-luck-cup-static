📋 Yahoo Sports (fallback)

Yahoo has no public API like ESPN, so "Fetch from Yahoo" works by pulling sports.yahoo.com/nfl/schedule/ (or college-football/schedule/ for FBS) server-side and running its text through the same parser as pasting by hand — a shortcut for the copy step, not a real API. That schedule page always shows the current week with no URL to update, unlike the old article-based pages this used to point at. Always check the preview below before importing either way.

  1. Or paste a different Yahoo page above if the schedule page ever stops working
  2. Find the weekly spreads article (e.g. "Full list of Week 8 spreads")
  3. Select all the game lines and copy them
  4. Paste below — the parser does the rest

How scoring works

Click ✅ Score Games That Are Over to auto-fill scores (and auto-lock any game that isn't locked yet) for every loaded game ESPN reports as final — click it again any time to pick up newly-finished games. A daily job also runs this automatically at 9 PM Pacific, so this button is mainly for checking sooner. Games ESPN doesn't have a clean match for still need a score typed in by hand below. Every player's points are calculated automatically from the locked spread (set at kickoff) the moment a score is entered, by hand or automatically — there's no separate "calculate" step.
✅ Cover = 2 pts  ·  🤝 Push = 1 pt  ·  ❌ No cover = 0 pts

🪙 Coin's Picks

Coin is the league's baseline: 10 random NFL games, each decided by a coin flip — heads picks the home team, tails picks the away team. Flip once games are loaded for the week. Flipping again adds more games to Coin's picks rather than replacing what's already there, same as if a player made more picks by hand.

💾 Save & Clear This Week

End-of-week ritual, once this week's games are all scored: archives the currently loaded games and everyone's picks for them under a saved record, then clears just those picks so next week starts at 0/10 for every player. Season standings still count archived weeks — they're read back in from the archive, nothing is lost.

🗑️ Clear All Picks (no archive)

Immediately wipes every player's picks with nothing saved first. For clearing out pre-season test picks before Week 1 — not for use once the season is live, since anything here is gone for good. Use "Save & Clear This Week" above for the normal weekly reset instead.
